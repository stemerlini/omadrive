# Omadrive

Keyboard-first two-pane file manager for Omarchy (C++ / Qt Quick). Local folders today; OneDrive via Microsoft Graph is planned.

Keys: `Tab` switch pane, `Space` mark, `Enter`/`→` open, `Backspace`/`←` up, `F5` copy, `F6` move, `F7` new folder, `F2` rename, `F8`/`Delete` trash, `Ctrl+H` hidden, `?` help, `Q` quit.

Originals are never overwritten: name clashes get a ` (2)` suffix.

```
bin/build     # build to build/omadrive
bin/test      # Qt Test suite
bin/install   # build and install the package
```
